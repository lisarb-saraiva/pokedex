

Pokedex é uma aplicação web que serve como um guia abrangente para Pokémon.  Permite que os usuários pesquisem informações sobre diferentes espécies de Pokémon, incluindo suas características, habilidades, tipos e evoluções.  O site é construído usando HTML básico, CSS e JavaScript puro, e utiliza a PokeAPI para buscar dados sobre Pokémon.

## Recursos

O Pokedex oferece os seguintes recursos:

- Procure Pokémon pelo nome ou número do Pokédex
- Obtenha informações detalhadas sobre um Pokémon específico, incluindo seus tipos, habilidades, estatísticas e evoluções
- Veja uma lista de todos os Pokémon e navegue por eles
- Filtrar Pokémon com base em seus tipos
- Ver Pokémon populares e suas classificações
- Ver Pokémon mais bem avaliados com base em suas estatísticas
- Explorar evoluções de Pokémon e seus caminhos evolutivos

## Instalação

Para instalar o Pokedex, siga estes passos:

1. Baixe o código-fonte do repositório: https://github.com/lisarb-saraiva
2. Extraia os arquivos do arquivo ZIP baixado.
3. Abra o arquivo `index.html` no seu navegador.

## Uso

Depois de instalar o Pokedex, você pode usá-lo abrindo-o no seu navegador.  Você pode procurar Pokémon usando a barra de pesquisa ou navegar pela lista de todos os Pokémon.  Clicar em um Pokémon exibirá suas informações detalhadas, incluindo seus tipos, habilidades, estatísticas e evoluções.
